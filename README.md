# Aholo Reality Skill — test3

最新版 test3 对用户的主要优势是：**更容易开始重建、知道怎么改善效果，也能自己决定最终保留哪个版本。**

## 用户优势

| 用户优势 | 具体体现 |
|---|---|
| **不懂参数也能开始** | 先说明素材和拍摄目标；不选参数就使用默认值，减少启动门槛。 |
| **有经验的用户可以提前控制效果** | 重建前可选择帧率、分辨率、训练量、高斯上限等，并了解各自的用途和代价。 |
| **物体与场景选择更清楚** | 提供室内／室外／物体入口，明确不同素材支持的重建方式。 |
| **等待过程更有信息** | 优先转述线上后台的预计剩余时间；无法读取时说明估时的不确定性。 |
| **直接在线查看结果** | 通过项目页看进度和模型，物体可切换环绕，无需打开本地 HTML 或先下载模型。 |
| **效果不好时有人引导** | 从缺块、重影、纹理模糊等现象出发，给出适用的检查和调参方案。 |
| **减少盲目重跑** | 能先检查原任务的蒙版、相机信息；需要重训时每轮只改一项，更容易判断是否有效。 |
| **最终决定权在用户手里** | 可以保留新版、退回旧版或停止调优；最后对比候选版本，自行选择交付版。 |

## 使用示例

用户只需说“椅背侧面有重影”，skill 就会结合素材类型说明下一步能试什么、改哪个值、可能增加哪些时间或资源开销，再让用户选择。

## 能力说明

这些优势主要来自更完整的操作和调优引导。**test3 没有更换底层重建算法，因此不保证每次调参都能提高画质。**
